
# Sales Data Analysis
This repository contains an analysis of annual sales data for retail store, aiming to derive actionable insights to boost sales performance in 2023.

## Project Overview
The project focuses on analysing customer behaviour and sales trends from 2022. By examining raw data, processed data, and visualizations, this analysis provides a foundation for data-driven decision-making. Key objectives include identifying high-performing channels, customer segments, and product categories.

## Questions (KPIs)
The analysis seeks to answer the following key performance indicators (KPIs):
1. What are the monthly trends in sales and order volumes?
2. Which sales channels (e.g., Myntra, Amazon, Ajio) contribute the most revenue?
3. How do customer demographics (e.g., age group, gender) influence sales?
4. What are the top-performing product categories (e.g., kurta, sets)?
5. How does regional performance vary across states and cities?
6. What is the distribution of order sizes and quantities?

## Process
The project follows these steps:
1. **Data Collection**: Analyse the provided `Raw Data` sheet, containing detailed order and customer information.
2. **Data Cleaning & Processing**:
   - Remove duplicates and handle missing values.
   - Add derived columns like `Age Group` and `Month` in the `Edited Data` sheet.
3. **Data Analysis**:
   - Perform exploratory data analysis (EDA) to uncover trends and correlations.
4. **Visualization**:
   - Create charts to visualize key insights (refer to sheets `1st chart` to `7th chart`).
5. **Dashboard Creation**:
   - Summarize results in the `Dashboard` sheet for an interactive overview.

## Project Insights
1. **Sales Performance**:
   - Monthly trends reveal peak sales periods.
   - Specific product categories and sizes drive significant revenue.
2. **Customer Demographics**:
   - Predominant customer age groups and gender distribution.
   - Patterns in purchasing behaviours based on demographics.
3. **Channel Analysis**:
   - Performance comparison of online platforms (e.g., Myntra, Ajio, Amazon).
4. **Regional Trends**:
   - Identify top-performing states and cities.
   - Evaluate potential markets for growth.
5. **Order Details**:
   - Insights into average order size, quantity, and value.

The analysis provides a comprehensive understanding of sales performance and customer behaviour. These findings can be used to:
